# Data

This folder contains the datasets used for the Underground to Breakout project.

## Files

### `platform_metrics.csv`

Weekly platform-level metrics collected from @WAR's publicly available profiles.

Includes:
- Spotify metrics
- YouTube metrics
- TikTok metrics
- Instagram metrics
- Collection dates
- Sources
- Notes and data limitations

### `release_event_log.csv`

A log of releases, collaborations, performances, media/playlist exposure and significant social media activity relevant to the project.

### `analysis_baseline.csv`

The baseline dataset used to establish the starting point for the analysis on **12 September 2026**.

## Data Collection

The initial tracking period runs from:

**12 September 2026 – 12 October 2026**

Data is collected weekly where possible.

## Data Quality

The project uses publicly available data. Some platform metrics may be rounded, abbreviated or unavailable. Missing data is recorded rather than estimated.
